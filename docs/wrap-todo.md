# wrap-todo —— 一轮寿命的执行清单(压缩后第一个动作 = 做完它然后清空)

> **只放执行,不放判断**:判断("当初为什么")是压缩前 wrap 的活,这儿不收。
> **一轮寿命**:压缩后第一个动作 = 做完它然后清空;下一轮 wrap 重新开始。
> **不许过夜**:条目过夜当场给去处(排进下一动作 / 记账拿号 / 等 owner 的写交接页),
> 三选一没有第四种——**清单是个没有去处的箱子,东西过夜 = 埋坑**。
> owner 一开口给新活 → 先干新活,清单往后排(但给去处不能省)。
