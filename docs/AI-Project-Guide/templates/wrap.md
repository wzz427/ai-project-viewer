# /wrap —— 压缩前的收尾:判时机 → 自检 → 存盘 → 扫文档 → 落盘 → 报告

> **挂载**:把本文件放到 `.claude/commands/wrap.md`(Claude Code)或 `.zcode/commands/wrap.md`(ZCode)
> 即成斜杠命令(⚠️ 下个会话才出现在菜单);同时建 `docs/warp-todo.md` 一轮寿命清单。
> owner 敲这个的意思是:**「我想 compact 了,先把该存的存好、该扫的扫完。」**
> 你不能替他执行压缩。你的交付 = 五句话 + 盘存干净。
>
> ## 🔴 只做一件事的两半,判据只有一句
>
> ### 做完所有**需要上下文**的判断,不做任何**不需要上下文**的执行。
>
> 敲它的时刻是上下文满了想腾空间——任何"顺手在这儿做掉"都是在烧正要腾出来的东西。
> 修 bug 需要代码和测试,不需要这段对话;判断"这份文档过没过期"恰恰**只有这段对话答得出**。
>
> | 留在 wrap(判断) | 搬进 wrap-todo(执行) |
> |---|---|
> | 记量出的数、owner 拍的板(连理由)、半截进度 | 修 bug、补测试 |
> | 扫同步表逐行判定哪份文档漂了 | 改那份文档的正文 |
>
> ⏱️ **5 分钟为界,超了 = 有东西漏进来了**,不是手慢。工作树里有代码 = 上一段活没做完,
> **先去做完再 wrap**,不是"提交掉再回来"。

## 第一步 · 判现在能不能压(这是我的活,不是 owner 的)

四条命中任一说"先别压":① 后台任务没回来(实验/压测/打包);② 有改了一半没验的代码
(答不出"上次测试什么时候、结果如何"= 没跑过);③ 对照实验中途;④ 欠 owner 一个
要靠这段上下文才答得出的答复。输出三选一:✅ 可以压 / ⏸ 先别压,等 X(约 N 分钟)/
⚠️ 能压,但有 N 处我兜不住。

## 第二步 · 快速自检(几秒)

工作树脏不脏 · 交接页该不该整批回收(翻不动=该)· 有没有还在跑的脚本
(**长任务活过压缩会被下个上下文再起一个,互相撞**)· 清单是不是空的。

## 第三步 · 把只活在对话里的东西写下来(永远排在第四步之前)

> **不可恢复的动作排在可恢复的前面**:没写下来的压缩后等于没存在;文档没扫随时能补(git 里一行不少)。

五类,一条一行、带指针、不展开:**① 这一轮量出来的每个数(连怎么量的)**
**② owner 拍的板/立的规矩/否掉的方向(连理由)——落进它们该住的正文,不是交接页**
**③ 干到一半的活**写成"下一步从哪接"(做到哪·下一动作·坑在哪)
**④ 答应 owner 的事 + 等他定的问题**(这一类**没有任何东西会提醒**)
**⑤ 临时目录里还要用的东西**——判据:**一个不记得任何对话的 agent,照这条能不能重建它?**
能 = 写下重建方法(两三句);不能且要留证的 → 搬进证据区(`test_case/` 一类)。
⚠️ 只记事实不记结论——**推断不许写成待办**。

## 第四步 · 扫文档同步表:判定当场做完,动手留给清单

逐行念 doc-maintenance §2,每行明确判定:**要改(改哪份、改成什么)/ 不涉及**,不凭记性。
动了 AGENTS.md/入口类文档 → 跑**路由回归**(装作新 agent 验"意图找得到吗")。
🚨 交付时必须列得出扫过的清单——**"都同步了"这句话本身不是证据**。
扫出的两条路:**纯替换**(一行说错的话改对,写条目比动手慢)→ 当场改;**别的一切** → wrap-todo。
🔴 推翻旧结论 → grep 旧那句逐处改,原地留"某月某日改口,出处 X"。

## 第五步 · 落盘(这里不跑完整测试)

测试是上一段活那笔提交的责任,wrap 只核实被履行过——**"引用上一趟"和"跑了测试"分开说**;
没有站得住的记录 → 写进清单,不在这儿现跑。然后:断链自查(动过 .md)→
`git add <明确列出的文件> && git commit`(工位板登记行不提交;活干完删行)→
`git push --force backup main --tags` → **核 `rev-list --count backup/main..main` = 0**。

## 第六步 · 给 owner 五句话

0. 第一行固定(有债务表时):**"还欠 N 笔,其中 M 笔随下次发版消掉——要清零的是 N−M=G 笔。"**(照抄)
1. 实测耗时(超了说清哪条没守住);2. 能不能压(三选一);
3. 存了什么、改了哪几份文档(带提交号;扫过的清单列出来);
4. 清单几条**逐条点名**(空项明说"没有了"——空项和忘了写长得一模一样;
   "只有他能做的"写"要你亲手做的:X");5. "可以敲 `/compact` 了,该保的都落盘了。"

🚫 不复述这一轮做了什么(提交说明里有,他刚看过);不给任何"粘贴到 compact 后面"的长指令——
**要保的东西必须在盘上,不在指令里。** 收尾自检:**"假设压缩后我一个字都不记得,
只会读交接页和清单——我还接得住吗?"** 接不住 = 第三步没做完,回去补。

## 压缩之后两步

① 清单做完并清空 → ② **回交接页接主线**(指路用名字不用位置)。

---

## 配套:wrap-todo 清单的规矩(写在 wrap-todo.md 头部)

- **只放执行,不放判断**;**一轮寿命**:压缩后第一个动作 = 做完它然后清空;
- **不许过夜**:过夜条目当场给去处(排进下一动作 / 记账拿号 / 等 owner 的写交接页),
  三选一没有第四种——**清单是个没有去处的箱子,东西过夜 = 埋坑**;
- owner 一开口给新活 → **先干新活**,清单往后排(但给去处不能省)。
