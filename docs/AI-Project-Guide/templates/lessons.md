# lessons —— 踩坑全集(只增不删;L 编号被别处引用,不重编不搬家)

> 一条合格的 lesson = **症状(真实报错字眼)+ 一句话根因 + 修法 + 判据**,不是叙事。
> 记的时机:踩坑**当天**,独立 commit。高频坑(被坑 ≥2 次或一次代价大)→
> 同步进 lessons-quickref(那边只放指针)。

## 条目格式

### L1:<症状一句话,贴真实报错字眼>

- **症状**:【撞到时看到什么——报错原文/坏掉的样子】
- **根因**:【一句话;怎么定因的(实验/日志/对照)】
- **修法**:【做了什么】
- **判据**:【下次怎么一眼认出它 / 怎么避开】
- **出处**:【哪次事故、哪个 SPEC,日期】
