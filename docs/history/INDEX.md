# history/INDEX —— 历史归档总目录(唯一入口)

> 每条 = 时间 · 主题 → 一句话结果 · Grep 关键词。想知道"当时做了啥、结果如何",
> 九成看本页就够;要刨完整经过再进对应文件 Grep。
> **归档和登记是两个动作**,做了前一个别忘后一个(真炸过:文件归档了、索引漏了)。

三条规矩:

1. **入口唯一**:任何文件进 history,必须在本页登记一行;查历史永远从本页进。
2. **内容冻结**:进了只读不改(修断链除外);还要维护的不许进——要更新的住活文档区。
3. **三轴分区**(落不进 = 它可能不是历史,回活区想清楚):
   - **时间轴 `progress/`**:handoff 整批蒸馏出的分期进展;
   - **版本轴 `releases/`**:changelog 滚动归档、每版发版快照(当时的关键配置/提示词样子——
     线上排查第一站:"它跑的是哪一版、那一版里到底是什么");
   - **快照轴 `standalone/` + `code-reviews/`**:定点评估、被取代的旧方案原文。
