> 项目文件夹或文件的功能」。

> V1.5——已撤回);同日 owner 立规「一定是先把方案都写清楚,要经我确认后再进行开发」
> ——已停工补流程(workflow §四硬门)。**方案呈报后 owner 认可,附两条修改**:①入口图标
> 换**放大镜**(准星「根本不知道什么意思」,要「用来查询路径的图标样式」);②侧栏头部

## §一 范围(使用者视角;V1.5 §200 增量节同文)

- 入口两枚:侧栏头部 Files/Git 页签右侧**放大镜**图标按钮(owner 定图标语义);快捷键
  **Ctrl+L**(浏览器地址栏肌肉记忆:输入地址→跳过去)。
- 弹出小对话框:一个路径输入框(打开即聚焦)+ 一句提示 + Locate 按钮;Enter=定位,
  Esc/点背景=关闭。
- 输入**绝对路径**(容错:首尾双引号剥掉——本应用「复制绝对路径」自带引号,粘贴自己复制的
  路径必须能直接用;正反斜杠均可;大小写不敏感;尾斜杠忽略):
  - 路径在某个**已打开项目**内 → 切到该项目页签(若不在前台),侧栏切到 Files,树自动展开
    祖先链并滚动到目标行:
    - 目标是**文件** → 与树单击完全同一语义:右侧打开该文件(§101 管线,大文件确认/
      二进制卡等行为原样),树高亮=激活页签;
    - 目标是**文件夹** → 该行高亮(右键「最后动作行」同一高亮语义)+ 展开它;
    - 目标**恰为项目根** → 只切项目页签。
  - 路径不在任何已打开项目内 → 错误提示,界面不动(**不自动加项目**——加页签是可见状态
    变更,留 owner 翻案;V1 先给明确的错,他想「顺手加上」是一行翻案)。
  - 路径在项目内但盘上不存在 → 错误提示。
  - 目标藏在**系统文件夹**里(node_modules/.git 等)且设置未开「显示系统文件夹」→
    错误提示指路(提示文案里写明去哪里开),不静默定位失败。
- 输入**相对路径**(无盘符/非根起头):按**当前激活项目**解析;无激活项目 → 同「不在项目内」错。
- 内存账(AGENTS 规矩 9):**零新增驻留**——对话框瞬态,关闭即弃;定位过程逐层现查
  (listDirectory 单层,复用树的 children 缓存),结果不持久化不缓存;快捷键只加一条
  分发表项。

## §二 关键决策(D1–D9 呈报获认可;D10/D11=owner 验后修改)

| # | 决策 | 理由/否决项 |
|---|---|---|
| D1 | 入口=侧栏头部图标+Ctrl+L 对话框,**不做常驻输入框** | 侧栏窄(180–600px),长路径常驻框又挤又丑;对话框=粘贴→Enter 两步,肌肉记忆同浏览器地址栏 |
| D2 | 文件目标走 `openFile`(树单击同一管线),**不另做「只亮不开」** | 本应用单击唯一语义=右侧展示(0.8.11 owner 立规);定位动词与单击同义,两套语义必漂 |
| D3 | 文件夹目标:定位+高亮+**展开该文件夹** | 「定位到文件夹」的自然期待是看到里面的东西(资源管理器双击语义);VS Code reveal 不展开——若 owner 更喜欢不展开,删一行 |
| D4 | 不在任何项目内=报错,**不自动加项目** | 加页签是可见状态变更;owner 若要「粘贴即加项目」,一行翻案(addProjectFromPath 现成) |
| D5 | 相对路径按**当前激活项目**解析,不跨项目猜 | 跨项目猜唯一命中才跳=复杂度换模糊收益;先做确定的 |
| D6 | 大小写/斜杠/引号/尾斜杠容错在**前端纯函数**做,项目匹配用**最长根前缀**(嵌套项目取更内层) | Windows FS 大小写不敏感;树行身份用盘上真名,逐层现查顺手把大小写校正成真名(revealTarget 靠 title 精确匹配,不校正=滚不到) |
| D7 | 逐层走查用树的 `ensureDirLoaded`(共享 children 缓存,不 force) | 定位顺路把走过的层填进缓存,revealInTree 随后零额外 IPC;不另建缓存(内存最小化) |
| D8 | 系统文件夹目标=报错指路,**不代开设置** | 改用户持久化设置不能是定位的副作用 |
| D9 | 快捷键 Ctrl+L(toggle:开↔关) | 语义=「地址栏」;Ctrl+P 易与打印/快速打开混淆 |
| D10 | **入口图标=放大镜**(owner 修改,替原准星) | owner:准星「根本不知道什么意思,要选那种用来查询路径的图标样式」——放大镜=查东西的通用符号 |
| D11 | **侧栏头部三图标垂直对齐修复**(owner 报障,顺手收口) | 真凶=刷新钮 `.glyph` 的 `inline-block` 让行内 svg 吃文字基线降部空隙,按钮被撑高 3.5px、图标相对顶高 ~1.75px(几何量测定凶,墨迹中心三者本只差 0.12px);改 `inline-flex` 后三钮同高 23px;历史潜伏,第三枚图标加入才显眼 |

## §三 实现

- `src/lib/services/locatePath.ts`(纯函数,vitest 直测):输入归一(引号/斜杠/大小写/
  盘符判定)→ 项目匹配(最长根前缀,ci)→ 逐段走查(注入 listDirectory,段名 ci 匹配
  出真名,收集 systemGenerated)。
- `src/lib/stores/locateStore.svelte.ts`:对话框开合 slot + `submitLocate(raw)` 编排
  (切换项目→侧栏 Files→走查→revealInTree/openFile/toggleExpand/高亮→toast 错误)。
- `src/lib/components/LocateDialog.svelte`:App 根部渲染(同 ErrorDialog/PropertiesDialog
  模式),打开即聚焦+全选。
- `Icon.svelte` 加 `search`(放大镜);`SidebarHeader.svelte` 加按钮(有项目才显示)+
  `.glyph` 对齐修复;`shortcuts.ts` 加 `ctrl+l`;`App.svelte` 接线+挂对话框;
  `dict.ts` en/zh 补 9 键。
- Rust **零改动**(全部前端+既有命令)。
- e2e(phase3 +11):Ctrl+L 开框+聚焦/Esc 关;对话框计算样式断言(铁律 §2.3-6);
  **三图标几何对齐守卫**(按钮高差+svg 中心差 <1px);相对路径(乱大小写)开文件
  (页签+树行高亮+折叠后重展开);绝对路径(引号+正斜杠)跨项目切换;文件夹定位
  (折叠后展开+高亮);不存在路径报错不加页签;node_modules 隐藏指路;纯根路径只切项目。

## §五 增量(2026-11-10,0.8.28):按名搜索补齐 V1.5 §148 Quick Open

> owner 报障原话:「我发现现在这个项目的文件搜索功能还是有问题,比如我搜索这个文件
> client-runtime-delivery-closeout.md,就搜不到,必须得给它一个比较完整的路径名,像类似
> 这样 docs/specs/designs/client-runtime-delivery-closeout.md 才能搜到」。
> 根因不在 bug 而在**缺件**:对话框把一切输入当**路径**从项目根逐段走查——裸文件名只在
> 项目根找,根下没有=「路径不存在」。V1.5 §148(P1)「Quick Open / 按文件名搜索项目文件」
> 从未实现,§149 定的实现约束(不建常驻索引、按需枚举、应用忽略规则、不许启动期全扫)
> 就是本增量的方案边界;放大镜图标(D10)本就承诺"查询"语义。按使用反馈模式(用户能感觉
> 到的 bug 一律修+体验渠道常设授权)当日修复发版,未再立新 SPEC。

**行为(增量后)**:

- **路径输入原样优先**——能从根走查通的,行为与 0.8.18 完全一致(0.8.25 的报错分流也不动)。
- 相对输入走查**失败**时 → 变成**当前项目内的名字搜索**(V1.5 §149 管线:按需递归枚举+
  树可见性规则+临时结果,零常驻):
  - 无分隔符=按**名字**匹配(全等>前缀>包含>路径包含);带分隔符=按**路径**匹配
    (段边界尾缀>包含)——「specs/designs/xxx.md」这类尾缀路径片段也能搜到;
  - 排序=匹配级→浅者先→字母序;**唯一命中直接跳**(owner 复现路径就是唯一名);
  - 多命中 → 对话框不关,**就地列前 50 条**(文件名醒目+所在目录置灰,↑↓/悬停高亮,
    Enter=高亮行,点击=所选行),超过就提示「多输几个字缩小范围」(收集上限 2000 防
    「a」类宽查询);列表随对话框关闭即弃;
  - 零命中 → 「当前项目内没有匹配的文件或文件夹:{输入}」。
- **绝对路径输入永不触发搜索**(带盘符=意图就是路径),保留 0.8.25 逐步指路报错。
- 排除项照抄树的隐藏目录表(.git/node_modules/…),且随「显示系统文件夹」设置放行——
  搜出来的东西必须树里能定位;**判定不做**:§148 的 Ctrl+P 键位不绑(owner 不用快捷键,
  入口就是放大镜按钮+Ctrl+L,要绑是一行翻案)。
